# 视觉资源

`valley-farm.png` 使用 Codex 内置 imagegen 生成，作为本项目的原创装饰背景；没有从游戏中提取素材。

最终提示词：

> Use case: stylized-concept. Asset type: wide decorative hero banner for a Chinese Stardew Valley companion web application. Create an original charming 16-bit pixel-art farm panorama strongly inspired by the visual language of Stardew Valley. Crisp square pixels, limited warm saturated palette, no smooth vector shapes, no 3D or photorealism. Very wide landscape composition around 4:1 ratio: pale blue pixel sky and fluffy stepped clouds above soft blue-purple mountains; below, a sunny lush green farm, little red-roof wooden cabin, golden wooden fences, orderly crop plots with green seedlings, parsnips and pumpkins, two adorable white chickens and a large leafy tree. Add a tiny round green leaf spirit among the crops as a small accent. Cozy, cheerful rural game atmosphere. The scene will sit above a parchment chat interface and wooden panels, so keep the composition uncluttered, readable at small size, and allow some sky breathing room. No interface, no text, no numbers, no logo, no watermark.

`PixelIcon.vue` 是本项目绘制的像素图标，包含作物、书本、宝箱、鸡、绿色森林精灵和紫色星形标识。

字体采用 [Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font)，保留在 `public/fonts` 中的 OFL 许可。像素字体用于菜单与标题，长篇攻略回答保留清晰的系统字体。
